# Public layout audit — August 2026

## Desktop

The workbench and public record pages retain a clear Vaultloom visual hierarchy. The main opportunity is structural rather than decorative: the cobalt rail should introduce a page’s current mode or record more consistently, and secondary public pages should avoid relying only on long document surfaces for hierarchy.

## Phone

All five public routes render without clipping at 375px. The primary navigation is nevertheless too dense for comfortable touch use, with its small labels competing for a single horizontal row. The homepage also needs a more explicit workbench sequence so the analyzer, guidance, and generator read as one instrument rather than a desktop split panel that simply stacks on phone.

## Refinement priorities

1. Give the phone header a scroll-safe, higher-contrast navigation treatment with a clear current-page indicator.
2. Add consistent record/mode labels beside signal rails, rather than treating the cobalt rail as a decorative edge.
3. Consolidate the workbench into a linear mobile sequence: orient, analyze, interpret, generate, then retain the privacy boundary and footer.
4. Preserve readable line lengths and field-report dividers on legal and support routes without reducing touch target size.

## Post-refinement verification

The revised workbench now presents an explicit Analyze → Interpret → Generate sequence before the interactive panels, preserving the full desktop instrument composition while making the phone flow easier to scan. The shared and workbench headers now render all five navigation destinations, including Terms, as visible touch targets on phone widths; the prior horizontal-scroll-only treatment was removed. Desktop and phone screenshots were taken for the workbench, About, Contact, Privacy, and Terms routes after this refinement.
